# To-Do List Application

A simple GUI-based To-Do List application built using Python and Tkinter.

## Features

- Add tasks
- Update tasks
- Delete tasks
- Complete and undo tasks
- Clear all tasks
- Save tasks
- Load saved tasks
- Track total and completed tasks

## Technologies Used

- Python
- Tkinter
- JSON
